#project_01_log_analyzer
硬件日志解析小工具

## 项目简介
针对嵌入式/硬件测试产生的文本日志，实现自动化日志扫描，自动抓取异常、错误、警告信息，统计异常数量，输出Excel分析报表。

适用场景：固件测试、存储硬件、嵌入式设备长时间测试日志批量分析，替代人工翻看日志，节省测试人员时间。
用途：读取硬件文本日志->过滤错误行->统计一场数量->导出Excel报表
技术栈：python + pandas + openpyxl

### 功能清单
✅ 读取txt硬件日志文
✅ 自动匹配错误关键词，过滤异常日志行
✅ 记录异常所在行号与原始日志内容
✅ 统计异常总条数
✅ 导出结果到Excel报
✅ 可自由配置异常关键词，适配不同硬件项目日志格式

目录说明：
main.py         #主程序入口
log_parser.py   #日志解析核心逻辑
config.py       #配置文件（错误关键词在这里自定义）
input/          #放原始硬件日志，比如log.txt
output/         #自动生成，输出解析后的Excel报告
