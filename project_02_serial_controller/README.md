# project_02_serial_controller
简易嵌入式串口采集上位机脚本（产线测试工具）

## 项目简介
面向嵌入式产线硬件测试场景，控制台串口工具。多线程实现异步串口数据采集，独立IO线程不阻塞控制台交互；支持串口指令下发、实时日志打印、本地日志持久化存储；增加异常捕获，处理设备热拔插、串口断开等异常。可扩展日志过滤、硬件状态解析、自动化测试脚本。用于嵌入式硬件调试、产线自动化采集。

## 功能清单：
1.打开指定串口，配置波特率、数据未、停止位、校验位
2.独立子线程持续读取硬件串口输出，不阻塞主线程
3.实时打印收到的串口日志，简单过滤无效空行
4.支持发送指令给下位硬件
5.可将采集到的串口日志保存到本地日志文件
6.无复杂GUI，控制台程序，产线自动化测试常用形态

技术栈：python、pyserial、多线程、curses
